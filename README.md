# InfluStance 소개 페이지

경제 유튜버가 지금 시장을 어떻게 보는지 정리하는 서비스 **InfluStance**의 소개 페이지입니다.
한 화면짜리 정적 페이지이며, 프레임워크와 외부 라이브러리를 쓰지 않습니다.

- 견본 사이트: https://influstance.pages.dev
- 오픈 소식 신청: 페이지 안의 버튼(구글폼)

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 슬라이드 3장 |
| `style.css` | 스타일 |
| `slides.js` | 슬라이드 넘기기(화살표·키보드·스와이프) |
| `og-default.png` | 공유 미리보기 이미지 |
| `.nojekyll` | GitHub Pages가 파일을 그대로 내보내게 함 |

## 로컬에서 보기

파일을 브라우저로 열거나, 간단한 정적 서버를 씁니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 사용자 지정 도메인

도메인이 정해지면 저장소 루트에 `CNAME` 파일을 만들고 도메인 한 줄만 적습니다.
그다음 저장소 **Settings → Pages → Custom domain**에 같은 값을 넣고 **Enforce HTTPS**를 켭니다.

## 방침

- 이 페이지는 특정 유튜브 채널·인물과 제휴 관계가 없습니다.
- 페이지 안의 사람 카드는 **예시이며 실제 인물이 아닙니다.**
- 투자 판단의 근거가 아닙니다.
